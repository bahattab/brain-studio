# Brain Studio 2.2.2

Fixed imported-questionnaire data lifecycle issues identified in the red-team review.

- Clear professional and imported workspace data reliably, including in-memory state; stale windows cannot restore deleted sessions. Exported files, legacy reflection profiles and saved AI providers are explicitly outside this action.
- Restore exported questionnaire answers into fresh storage with validated identity and recomputed scores. Large answer exports have consistent bounded support in desktop and web editions.
- Start a separate, empty respondent session while keeping earlier sessions independently identifiable.
- Preserve older imported records with an explicit attribution-review requirement before report export; no historical ownership is silently inferred.
- Delete questionnaires or respondent sessions; accurate capacity notices explain how to free space.
- Updated all 30 interface languages and added failure-path/browser/native regressions.

## العربية

يصلح هذا الإصدار المسح والاستعادة وفصل جلسات المستجيبين وإدارة سعة الاستبانات. تبقى السجلات القديمة محفوظة مع طلب مراجعة صاحب الإجابات قبل التصدير. لا يغيّر الإصدار مفاتيح التحليل التجريبية إلى مفاتيح رسمية.

The release contains public application code and synthetic tests only. Personal questionnaire packages are supplied separately. Native packages are unsigned development distributions; the experimental assessment limitations remain unchanged.

The browser import tests explicitly await asynchronous file processing so fast CI hosts do not assert against a previous notification.
