# Brain Studio 2.2.3

This release repairs imported-questionnaire data handling and addresses further library review findings.

- Clear professional and imported workspace records, including stale in-memory sessions. The confirmation identifies external exports, legacy reflection profiles and saved AI providers as outside this action.
- Restore exported questionnaire answers with validated session identity and recalculated scores, including large bounded exports.
- Start independent respondent sessions; migrated records require explicit attribution review before report export.
- Delete questionnaires or sessions, release capacity and show accurate limit messages.
- Apply complementary suppression to private feedback reports so a small role group cannot be recovered by subtracting other displayed group means. Private exports omit raw ratings and individual priority-overlap records.
- Reject repeated profile identities and hide extrema for three- and four-person aggregate teams. Explicit two-person discussion remains a consented, nonanonymous feature.
- Remove aggregate role-fit count rankings, vary practice option positions without changing canonical answers, and normalize case variants in rubric topics.
- Show preparation and privacy information at the first question, explain the five IPIP factors in plain language, and avoid forcing an interest-theme choice when no O*NET activities were selected.
- Improve 153 existing Arabic translations. Other interface languages retain draft linguistic status; coverage tests do not certify language quality.
- Update Electron to 44.9.3 and patch vulnerable build dependencies. Full dependency audit passed with zero known vulnerabilities at verification time.

The Electron update includes the vendor's mitigation for compromised certificate intermediates: [Electron security advisory](https://github.com/electron/electron/security/advisories/GHSA-jr5w-w6x2-84p9).
