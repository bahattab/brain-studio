# Brain Studio 2.2.4

Imported questionnaire screens show four navigation actions. On narrow screens those actions previously extended outside the question panel. They now wrap within the panel, so Previous, Next, Report and Home remain reachable. Verified in Arabic and English at320,390 and600px with a browser regression that checks both page overflow and each button boundary.

Private questionnaire adaptations are distributed separately to the source owner. No private questions, personal reports or experimental keys are included in this repository or public installers. Content review and successful software tests do not establish ordinary-user comprehension, psychometric validity, reliability or equivalence with proprietary instruments. The adapted packages remain explicitly experimental pending actual participant studies.

Native distributions remain unsigned. AI provider verification and other existing limitations are unchanged from the previous release.
