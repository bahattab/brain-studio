# O*NET® Interest Profiler Short Form implementation

The [official Interest Profiler page](https://www.onetcenter.org/IP.html) lists a 30-item Mini-IP web form and a 60-item paper Short Form for the six RIASEC interest areas. A complete official source is accessible: [English Short Form PDF](https://www.onetcenter.org/dl_tools/ipsf/Interest_Profiler.pdf).

That PDF asks respondents to check appealing activities and count checks in each of six groups of ten; scores run 0–10. It lets respondents choose among tied interests by considering which activities fit best. This paper-form score must not be fabricated by applying the IPIP 1–5 scale, invented reverse keys or an automatic alphabetical tiebreaker. The online Mini-IP is a distinct format; obtain and verify its exact item set, anchors, key and scoring specification separately.

The [tools license summary](https://www.onetcenter.org/license_tools.html) permits verbatim redistribution under CC BY-ND 4.0, retaining source credit and a license link. The [Developer License](https://www.onetcenter.org/license_toolsdev.html), section 3(b), requires validation studies for changed purposes or changed content; software-only integration is expressly exempt from the content-modification clause. Thus an English software-only integration preserving the complete instrument and purpose is feasible. Translated items or shortened/invented forms are content modifications and require the validation conditions before product introduction. No public-domain assumption applies here.

**Implemented:** the complete original English paper Short Form in `ResearchCore`, ID `onet-short-form-60`. Its 60 prompts, source instructions and tie instructions were independently extracted from the live official PDF and compared exactly. `onet-60-source-fixture.json` records normalized source text and SHA-256; `onet-interest-profiler-original.pdf` retains the full unchanged licensed original. The PDF activities have no individual numbers. Stable software IDs use the PDF's row-major two-column reading order within each RIASEC section, with whitespace and checkbox glyphs normalized but wording unchanged.

Responses are explicit 0 (unchecked) and 1 (checked). Missing properties are unconfirmed rather than silently treated as zero; all 60 must be confirmed. Six checked-count sums run 0–10, and means run 0–1. Tie groups preserve all equal-scoring themes, including ties at the third position. The source's respondent-choice instruction remains available; no arbitrary priority or three-letter code is assigned. Manual test references include six single-theme vectors, mixed counts `[9,8,7,6,5,4]`, cutoff ties `[9,8,7,7,3,1]`, primary ties and all-zero ties.
